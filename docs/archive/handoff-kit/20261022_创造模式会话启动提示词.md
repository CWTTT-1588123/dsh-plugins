- handoff-pack 技能；
- 无 UI、无 Client 半区、无 LLM、无 DB、无自动阈值/compact 钩子；
- 用户级输出 ~/.dsh/handoff/<project-key>/；

- Host 代码在沙箱外；写用户路径必须走 ctx.fs + sandboxPolicy；
- 读也要工作区 allowlist，防 ..、绝对路径、symlink 逃逸；
- 不联网、不起子进程、不调 LLM；
- 不改 DSH 官方源码；安装/激活用 plugin_manager，失败要能回滚。
