## 6. 可信度外层（M5）

- **签名**：`signature.json` 为 sidecar（不进 `SHA256SUMS`/manifest），Ed25519 签 `SHA256SUMS`
  字节；`keyId=sha256(publicKey PEM)[:16]`；验证四态 `unsigned/valid/untrusted/invalid`，仅
  `invalid` 产生 `SIGNATURE_INVALID` error；信任源 `--pubkey` → `trusted-keys.json` → 无。
  私钥只由 CLI `--key` 读取。
- **策略**：`$DSH_HOME/handoff/policy.json` 严格 schema、只能追加、内置地板不可关闭、非法配置
  fail-closed（`HANDOFF_POLICY_INVALID`，写前失败）；provenance 记入
  `evidence/redactions.json.policy`；`migrate` 不读策略。
- **回执**：verify/load 结果级 `receipt`（只读、不落盘；除 checkedAt 外稳定）。
- 负例测试：坏签名/篡改 `SHA256SUMS`/未知算法/坏策略/过期字段 → 对应错误或降级，默认路径与
  无策略行为不变（`test/signature.test.js`、`test/policy.test.js`）。

## 7. 转接增强（A1/A2）

- 开场提示词（`src/ui.js::renderOpeningPrompt`）步骤 0–4：强制只读门 → 概念（H2→H3→H4→H8）→
  **实际读取关键文件**（role 优先，≤8）→ **re-grounding**（叙述 vs 当前代码/引用路径）→
  汇报（trust/核对过的文件/不符清单）+ 等用户指令。
- `HANDOFF_PATH_MISSING`：生成时引用的仓库相对路径缺失记 warning（不阻断）；verify/load
  （有 workspace 时）记 warn finding（trust=stale，不判 invalid）；忽略 URL/纯文件名/空格/逃逸；
  `$DSH_HOME` 不解析。
- 用户实测反馈（M4 后）：旧批次显示 `trust=stale` + 9 条漂移警告（`GIT_HEAD_CHANGED`、
  `SOURCE_FILE_CHANGED`、文档引用失效等），新提示词要求新会话实际打开文件核对，而不是照单全收。

## 8. 批次删除（M5b）与回滚演练

- 软删除：目录移入 `<handoffRoot>/.trash/<projectKey>/<batchId>-<UTC timestamp>[-n]/`；原路径
  消失、`.trash` 不参与项目扫描；**回滚演练**：软删 → 从 `.trash` 移回原路径 → `verify` 再次
  `verified`（实测通过，2026-10-23）。
- 硬删除：CLI `--hard`（不可恢复，输出强警告）；单测覆盖。
- 血缘保护：被其它批次 `lineage.previous/supersedes` 引用 → `HANDOFF_BATCH_REFERENCED`；
  `--force` 才允许并输出 `BATCH_REFERENCED_FORCE`（后代可能 `LINEAGE_BROKEN`）。
- UI：工作台/载入面板删除按钮 + 二次确认（只发软删）、中英文案、错误 toast；RPC `delete` 对
  `projectKey` 严格校验（防穿越），历史批次可软删。
- 宿主 `ctx.fs` 无 rename/remove 原语（GAPS G3）：实现优先可选 `fs.rename`/`fs.remove`，否则
  回退 `node:fs` 本地文件系统（先过 target/sandbox 写权限门）。

## 10. 已知缺口与限制（如实记录）

1. **`plugin_manager` 安装源切换缺陷**：运行中 link↔npm 切换需重启；本机 `remove_bundle` 对
   `link:` 目标会清空目录（已恢复）。M4 安装演练结论：只能「备份 + 重启」。见 GAPS §3。
2. **宿主 fs 无 rename/remove**：删除在远程/非本地后端且无可选能力时不可用（GAPS G3）。
3. **`migrate` 不读取 policy**（只复制源批次）；策略只约束 create/append/update（+scan 预览）。
4. **不包含旧对话原始消息正文**（隐私/成本/宿主限制）；交接=「叙述+证据+re-grounding」，
   不是对话回放。
5. **平台**：Windows 优先，macOS/Linux 实验性（CI 非阻塞）；未做跨平台删除/路径 E2E。
6. **签名信任**：默认 opt-in 且需本地信任源；无撤销/透明日志；provenance/trusted publishing
   未接入 CI（1.x 可加）。
7. **UI**：历史 project-key 批次只读（可软删）；`--hard` 仅 CLI；工作台删除按钮/新提示词需
   重启 DSH 后可见（M6 用户抽查项）。
8. 过宽自定义脱敏规则可能命中终检而拒绝生成（fail-closed，属预期安全行为）。
